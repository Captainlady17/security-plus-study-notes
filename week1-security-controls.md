# Week 1 - Security Controls (1.1) - Detailed Notes

## What is a security control?
A security control is any method, tool, or rule used to protect a system, network, or organization from threats. Think of it as any "safety measure" - some are digital, some are physical, some are just rules people follow.

---

## Part 1: Categories of Security Controls
(These describe HOW the control works)

### 1. Technical Controls
Controls implemented using technology/software/hardware.
- Examples: Firewalls, antivirus software, encryption, passwords, multi-factor authentication (MFA)
- Simple idea: "The computer/system itself is doing the protecting"

### 2. Managerial Controls
Controls created through policies, procedures, and decisions made by management/leadership.
- Examples: A company's password policy, risk assessment procedures, security awareness training programs
- Simple idea: "Rules written down by the people in charge"

### 3. Operational Controls
Controls carried out by people, day-to-day, to maintain security.
- Examples: Security guards checking ID badges, employees locking their screens, staff attending training
- Simple idea: "What people actually DO every day to stay safe"

### 4. Physical Controls
This control type limit someone access to a particular resource.
Controls that physically block or limit access.
- Examples: Locked doors, security cameras, fences, biometric scanners (fingerprint locks)
- Simple idea: "Things you can physically touch/see that stop intruders"

---

## Part 2: Control Types (by Purpose)
(These describe WHY/WHEN the control is used)

### 1. Preventive
Stops an incident BEFORE it happens.
- Example: A locked door, a firewall blocking bad traffic, requiring strong passwords

### 2. Deterrent
Discourages someone from even TRYING to attack.
- Example: A "Beware of Dog" sign, visible security cameras, warning banners on login screens

### 3. Detective
Notices/identifies that something bad IS happening or already happened.
- Example: A security camera recording, an alarm system, log monitoring software

### 4. Corrective
Fixes the damage AFTER an incident occurs.
- Example: Restoring data from a backup, patching a vulnerability after an attack

### 5. Compensating
An alternative control used when the main/ideal control isn't possible.
- Example: If a company can't afford advanced firewalls, they might rely on extra staff monitoring instead

### 6. Directive
Tells people what they MUST do (instructional).
- Example: A policy sign that says "All employees must wear ID badges," or a rule requiring password changes every 90 days

---

## How Category + Type combine (important concept)
A single real-world control can belong to ONE category AND ONE type at the same time.

Example: A security camera
- Category: Technical (it's electronic equipment) OR Physical (it's a physical device) - can be both depending on context
- Type: Detective (it notices/records an incident)

Example: A company policy requiring background checks before hiring
- Category: Managerial (created by management)
- Type: Preventive (stops a risky person from being hired in the first place)

---

## Simple real-life example to remember everything:
Imagine protecting your home:
- Lock on the door = Preventive + Physical/Technical
- CCTV camera = Detective + Technical/Physical
- "Beware of Dog" sign = Deterrent + Physical
- Fixing a broken window after a break-in = Corrective
- House rule "always lock the door when leaving" = Directive + Managerial
- Using a neighbor to watch your house when your alarm system is broken = Compensating

---

## Why this topic matters for the exam and real jobs:
Understanding control categories and types is the FOUNDATION of cybersecurity thinking. In real SOC/GRC jobs, you'll constantly be asked: "What type of control should we use here?" - so this isn't just exam theory, it's how professionals actually talk about security solutions.
